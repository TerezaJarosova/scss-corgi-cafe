# scss-corgi-cafe
Sample website built with HTML and SCSS, showcasing styling techniques.

## Description
This project serves as a **demonstration of working with SCSS**. The main focus is on **modular, maintainable CSS with variables, nesting, and mixins**.
Responsiveness and interactivity are not implemented, as the goal is to highlight SCSS structure and styling capabilities.
For a fully responsive and interactive project, visit  [career.theas.design](https://career.theas.design)
or my repositories [career-theas-design](https://github.com/TerezaJarosova/career-theas-design),
[contact-form](https://github.com/TerezaJarosova/contact-form),
[iframe-component-overlay](https://github.com/TerezaJarosova/iframe-component-overlay).

## Technologies
- HTML
- SCSS

## Features
- Modular SCSS structure (variables, nesting, mixins)
- Styling for headers, cards, and sections
- Visual emphasis on layout and typography
- Focus on maintainable CSS practices

## Running the Project
Open index.html in your browser
